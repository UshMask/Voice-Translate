# Voice Translate для Windows

[English](README.md) · [Исходный код](https://github.com/UshMask/Voice-Translate) · [Выпуски](https://github.com/UshMask/Voice-Translate/releases)

Распознавание, обработка и перевод речи в приложении для Windows, работающем в трее.
Это форк [Voica для Windows](https://github.com/Inhum/voica-win), созданной Иваном Ушаковым.
Здесь готовится самостоятельный публичный форк; это не официальный выпуск Voica.

## Возможности

- Локальное распознавание русской речи через GigaAM v3 или облачное через Groq Whisper.
- Вставка результата в активное поле либо показ в редактируемом окне.
- Необязательные перевод с русского на английский и обработка текста выбранной API-моделью.
  Порядок перевода и обработки настраивается.
- OpenRouter, RouterAI или Царь Роутер — отдельно для каждого этапа.
- Словарь, правила исправления и локальная история с результатами этапов.
- Постоянный перетаскиваемый островок микрофона и необязательный локальный черновик речи.

Поддерживаются Windows 10 1809+ и Windows 11, x64. Интерфейс — русский и английский.
Локальное распознавание работает с русским языком. Черновик приблизительный и расходует
дополнительные память и процессор.

## Запуск из исходников

Установите .NET 8 SDK с поддержкой Windows Desktop, выполните `build-local.bat`, затем
`ЗАПУСК.bat`. В сборке разработчика сохранено внутреннее имя `Voica.exe`.

1. В «Настройки → Распознавание» скачайте совместимую модель GigaAM (~215 МБ) или выберите
   папку уже установленной модели. Файлы проверяются перед импортом.
2. В новых настройках выбрано локальное распознавание, перевод и обработка выключены.
   Включить их можно в разделе «Перевод и обработка». Существующие настройки сохраняются.
3. Для перевода или обработки выберите провайдера, сохраните ключ соответствующего этапа,
   укажите доступный ID модели и сохраните параметры. Запросы могут быть платными.
4. Выберите поле ввода. Правый Alt начинает запись, повторное нажатие завершает её.

Если выбранному движку не хватает модели или ключа, настройки откроются в разделе
«Распознавание». Если не настроен включённый перевод или обработка — в соответствующем
разделе. Короткая подсказка укажет следующий шаг. Скачивание модели и проверка API
запускаются пользователем.

Выпускной процесс готовит установщик для текущего пользователя
`VoiceTranslate-Setup-<версия>.exe`, архив `VoiceTranslate-<версия>-win-x64.zip` со средой .NET
и архив `VoiceTranslate-<версия>-win-x64-fx.zip`, которому нужен .NET 8 Desktop Runtime.
В обоих архивах — `VoiceTranslate.exe` и комплект лицензий; сохраняйте их вместе. Локальная сборка не означает публикацию релиза.
Подробности — в [инструкции](README-Voice-Translate.md).

## Данные и сеть

Настройки, ключи под защитой Windows DPAPI, история и необязательные записи находятся в
`%APPDATA%\VoiceTranslate`. Модель также может использоваться из
`Документы\VoiceTranslate\models`. Пути существующих данных сохраняются при обновлении.
У форка отдельные идентификатор установки и папка, отличные от оригинальной Voica.

При локальном распознавании аудио остаётся на устройстве. Облачное распознавание отправляет
аудио в Groq, исправление терминов через ИИ — текст в Groq. Включённые перевод и обработка
отправляют текст и инструкции выбранному провайдеру. Локальное распознавание само по себе
не делает последующие этапы офлайн. У приложения нет собственного бэкенда и телеметрии.

Обновления программы проверяются в этом репозитории. Закреплённая модель GigaAM скачивается
из отдельного выпуска исходной Voica: источник модели не зависит от обновлений форка.
Модель не включена в установщик. Настройка прокси действует на сетевые запросы приложения.
