# Voice Translate

Персональная версия [Voica для Windows](https://github.com/Inhum/voica-win), автор Ivan Ushakov, лицензия MIT (см. LICENSE). Локальное распознавание GigaAM v3 E2E CTC int8 и перевод с русского на английский через OpenRouter, модель tencent/hy-mt2-30b-a3b.

Настройки открываются с меню разделов слева: «Диктовка», «Распознавание», «Перевод и обработка», «Словарь», «Внешний вид», «Данные и приватность», «Сеть», «О программе».

## Начало работы

1. Запустите ЗАПУСК.bat. Если сборки нет, выполните build-local.bat, затем ЗАПУСК.bat.
2. В разделе «Перевод и обработка» выберите нужные этапы. Для перевода и обработки сохраните API-ключ OpenRouter и настройте баланс. Для одного локального распознавания ключ не нужен. Ключ защищён Windows DPAPI.
3. В разделе «Распознавание» выберите локальный движок (он выбран по умолчанию) и при необходимости нажмите «Выбрать установленную модель…» и укажите папку с файлами совместимой модели либо скачайте её (~215 МБ). При запуске программа также ищет модель в типичных папках Voica и GigaAM и кэше Hugging Face; если находит, предлагает скопировать её. Проверяются имена, размеры и SHA-256. Поддерживается именно GigaAM v3 E2E CTC int8 ONNX, другие форматы модели несовместимы. Модель обычно хранится в %APPDATA%\VoiceTranslate\models. Если там её нет, программа автоматически использует совместимые файлы из папки «Документы\VoiceTranslate\models». Обе папки сохраняются между обновлениями EXE.
4. Выберите поле ввода и нажмите правый Alt один раз, говорите по-русски и нажмите его снова. Другую клавишу или сочетание можно выбрать в настройках диктовки. Окно результата вместо вставки включается там же.
5. Значок программы находится в системном трее; через него открываются настройки, история и выход.

Звук распознаётся локально и по умолчанию не сохраняется после обработки. Перевод и обработка включаются отдельно. Порядок обработки и перевода можно выбрать в разделе «Перевод и обработка»; для существующих настроек сохраняется прежний порядок — перевод, затем обработка. При включении только обработки она получает русский текст. Словарь терминов передаётся модели обработки как подсказка. История новых записей содержит этапы распознавания, обработки и перевода. Для обработки укажите ID модели OpenRouter, выберите или измените промпт и нажмите «Сохранить» рядом с шаблонами. Галочки применяются сразу; настройки выключенного этапа скрываются, а сохранённые значения остаются. При сбое этапа последнее успешно полученное содержимое показывается в отдельном окне. Включённые этапы отправляют текст в OpenRouter и могут быть платными; история сохраняется локально. Ключ и данные приложения хранятся отдельно от Voica в %APPDATA%\VoiceTranslate. Программа не отправляет сообщение за вас.

Если при обработке переключиться на другое окно, перевод откроется отдельно. Проверка не различает поля внутри одного окна: не меняйте фокус внутри него до вставки. При ошибке перевода оригинал показывается в окне. Плавающая панель Voica появляется при записи и обработке; в остальное время программа находится в трее.

Voica сохраняет настройки источника для дополнительных сценариев (включая Groq), но для задачи используйте локальную GigaAM. Автоматическая проверка обновлений отключена; обновления оригинальной Voica не содержат добавленный перевод.

## Провайдеры

Для каждого этапа отдельно выберите OpenRouter, RouterAI или Царь Роутер и сохраните ключ для выбранного этапа и провайдера. Укажите ID моделей из каталога выбранного сервиса и нажмите «Сохранить» под промптом. ID HY-MT2 по умолчанию относится к OpenRouter; его наличие в других сервисах не гарантировано. При выборе другого провайдера прежний ID автоматически не меняется. Прежний ключ OpenRouter доступен обоим этапам до сохранения или удаления отдельного ключа. Сохранённый ключ показывается условной маской: чтобы заменить его, введите новый ключ и нажмите соответствующую кнопку сохранения.

## Черновик речи во время записи

В разделе «Внешний вид» можно включить показ черновика речи. Он работает с локальной GigaAM при включённой плашке записи: отдельный островок над ней показывает примерно последние 8 секунд с обновлением раз в несколько секунд. Черновик может меняться и отличается от итогового текста, который распознаётся по всей записи после остановки. Для черновика используется отдельный локальный экземпляр модели, поэтому расходуется дополнительная память и процессор. Аудио для черновика в облако не отправляется.

## Постоянный островок

В разделе «Внешний вид» включите «Всегда показывать островок». Микрофон запускает запись, шестерёнка открывает настройки, а кнопка с булавкой закрепляет или открепляет островок. Закреплённый островок остаётся на экране между записями; откреплённый скрывается после записи. Крестик во время записи отменяет её, галочка завершает запись и запускает распознавание. Островок можно перетащить мышью за любую часть; его положение сохраняется. Горячая клавиша продолжает работать.
